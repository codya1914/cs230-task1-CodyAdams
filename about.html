What is HTML?

HTML stands for HyperText Markup Language. It is used to organize the content of a webpage.

Basic HTML Structure

  1. DOCTYPE declares the HTML version.
  2. HTML contains the entire webpage.
  3. Head contains information about the page.
  4. Body contains the visible content.

Common HTML Tags

Tag Purpose
<h1> Main heading
<p> Paragraph
<a> Link
<img> Image
<ul> Unordered list
